# Replywise demo

This package contains the standalone Replywise interface preview.

## Run it

Open `index.html` in a modern web browser. No build tools or install are required.

## Important

This is a frontend demo. It uses fictional sample conversations and does not connect to an email account, read messages, save drafts, or send email. Real multi-user email support requires a secure backend and a separate OAuth authorization flow for every user. Do not put passwords, OAuth tokens, or API keys in this HTML file.
